# Material slots

Blender で `MAT_` から始まるマテリアルを差し替えると、同じ用途のオブジェクトをまとめて更新できます。

| Slot | Purpose |
| --- | --- |
| `MAT_MAIN_WALL_PLASTER` | メイン壁面。暗い漆喰・石壁向け |
| `MAT_MAIN_FLOOR_STONE` | メイン床。石・古材向け |
| `MAT_MAIN_WOOD` | メインの机、椅子、腰壁、梁 |
| `MAT_MAIN_METAL` | 真鍮風の金物、照明枠 |
| `MAT_MAIN_UPHOLSTERY` | メイン椅子の張地 |
| `MAT_SUB_WALL_IVORY` | サブ壁面。暖色寄りの白 |
| `MAT_SUB_FLOOR_MARBLE` | サブ床。白木・淡色石材向け |
| `MAT_SUB_TRIM_WHITE` | サブの机、装飾、建具 |
| `MAT_SUB_ACCENT_BLUE` | 淡い青の差し色 |
| `MAT_SUB_UPHOLSTERY_ROSE` | サブ椅子の張地 |
| `MAT_CORRIDOR_WALL` | 二部屋をつなぐ中間色 |
| `MAT_ELEVATOR_WOOD` | EV内装の木質パネル |
| `MAT_ELEVATOR_CARPET` | EV床の深い青色カーペット |
| `MAT_ELEVATOR_MIRROR` | EV奥の鏡・反射パネル |
| `MAT_SCREEN_PLACEHOLDER` | Unity で共有講演 RenderTexture 用素材へ置換 |
| `MAT_PORTAL_PLACEHOLDER` | 異界の門の低遅延映像用。方式確定までは発光プレースホルダー |

実テクスチャを入れる場合もマテリアル名は維持してください。Unity のセットアップツールが名前を手掛かりにスクリーンなどを識別します。
