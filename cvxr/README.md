# cvxr

ChilloutVR 用のアセット、Unity/CCK のバージョン情報、導入手順を格納します。Unity の `Library/` など再生成可能なキャッシュはコミットしません。

## プロジェクト

- [`castle-of-ideas/`](castle-of-ideas/): 二つの講義室と廊下からなる汎用ワールド **Castle of Ideas**

新規制作には CCK 4（作業開始時点は 4.0.1）と Unity 2022.3.58f1 を使用します。CCK の配布物はこのリポジトリへ再配布せず、[公式セットアップページ](https://docs.chilloutvr.net/cck/setup/)から各自で導入してください。
