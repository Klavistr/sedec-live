# SEDEC Livestreaming

成人向け二次元同人作品制作勉強会「性DEC」の配信・録画向け資産をまとめるリポジトリです。OBS Studio向けの画像/映像/HTML素材やシーンファイル、ChilloutVR用アセット、会場3Dモデルなどを対象とします。トンマナや運用ノウハウは Klavistr/sedec-d11n を参照してください。

## 概要
- 目的: 配信/録画に必要な素材とツール一式を整備し、再利用しやすくする。
- 対象範囲: OBSソース（画像・動画・HTML）、シーンコレクション、ChilloutVRアセット、会場3Dモデル、補助スクリプト。
- 関連ドキュメント: トンマナ/オペレーションは Klavistr/sedec-d11n を参照。

## 想定機能 (計画)
- OBS Studio: シーンコレクション、トランジション、ブラウザソース、スティンガー、ローワーサード。
- ChilloutVR: アバター/プロップアセット、ワールド連携、インタラクションスクリプト。
- 3D会場: ステージ/レイアウトモデルとライティングプリセット。
- 自動化: メディア取り込み、バンドル書き出し、設定検証のヘルパースクリプト。
- ドキュメンテーション: オペレーター手順書、アセットスタイル注記、チェックリスト。

## リポジトリ構成 (案)
- `obs/` ? シーンコレクション、プロファイル設定、メディアパック。
- `assets/` ? 画像/動画/HTMLオーバーレイのソースと書き出し物。
- `cvxr/` ? ChilloutVR アセットと導入手順。
- `models/` ? 会場/ワールド用3Dモデルとライティングプリセット。
- `scripts/` ? エクスポート、検証、パッケージングのヘルパー。
- `docs/` ? プロジェクト固有ドキュメント。トンマナ/運用は Klavistr/sedec-d11n へ。

## 基本的な使い方
- OBS: シーンコレクションをインポートし、メディアルート/音声バス/スティンガーを確認。
- ChilloutVR: ワールド/アバターパッケージをインポートし、インタラクションとシェーダーを確認。
- 3Dモデル: DCCで開き、ライティング調整後に FBX/GLB 等でエクスポート。
- オーバーレイ: HTML/CSS を更新し、ローカルプレビューサーバー（スクリプト [TBD]）を起動して OBS のブラウザソースに指定。

## 配信ワークフロー (たたき台)
1. 事前確認: 入力系（マイク/キャプチャ）、メディアルート、ビットレート/プロファイルを確認。
2. シーンコレクションを読み込み、Klavistr/sedec-d11n のチェックリストを実施。
3. ブラウザソース/ローワーサードの動作とタイミングを確認。
4. トランジション/スティンガーと音声ダッキングをテスト。
5. リハーサル録画を行い、VOD を確認。
6. 本番配信: ドロップフレーム/遅延を監視し、バックアップ録画を維持。
