# アセット管理ガイド

## 原則

配信当日に必要なファイルを見つけやすくし、別の端末でも再現できることを優先します。編集可能なソース、OBS が直接参照するファイル、再生成できる出力を区別してください。

## 命名

- 原則: `kebab-case.ext`
- イベント固有: `sedec-YYYY-purpose-variant.ext`
- サイズ違い: `name-1920x1080.ext`
- 日付は `YYYY-MM-DD`
- `final-final2` のような名前を避け、必要なら Git のタグやリリースで版を管理する

## ディレクトリ

- `assets/images/`: ロゴ、背景、登壇者画像、図版
- `assets/audio/`: BGM、ジングル、効果音
- `assets/video/`: スティンガー、待機映像、ループ映像
- `assets/overlays/`: OBS ブラウザソース。1 オーバーレイ 1 ディレクトリを基本とする
- `models/`: Blender などの編集可能な 3D ソース
- `obs/`: OBS からエクスポートした共有設定

## 第三者素材

第三者素材を追加するときは、同じディレクトリの README に次を記録します。

- タイトルとファイル名
- 作者・配布元 URL
- ライセンスまたは利用許諾
- 取得日
- 加工内容

情報が確認できない素材は追加しません。

## 容量

現在 Git LFS は設定されていません。10 MiB を超えるバイナリはコミット前に格納方法を決め、50 MiB を超えるファイルは `make check` が警告します。レンダーや録画のように再生成できる大容量ファイルは原則としてコミットしません。

## OBS

- シーンコレクションは `obs/scene-collections/` に JSON で保存する
- プロファイルは秘密情報とマシン固有情報を除いて `obs/profiles/` に置く
- 配信キーやサービス認証情報をエクスポートしない
- メディア参照はリポジトリ内の相対パスを優先する
- コミット前に別ユーザー環境で不足ファイルがないか確認する
