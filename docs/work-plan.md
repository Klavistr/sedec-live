# 作業計画

README の構想を、Codex で着手しやすい単位に分解したバックログです。上から順に進める必要はありませんが、最初の配信パックを優先します。

## 1. 配信仕様を決める

- [ ] 対象イベントと配信先を決める
- [ ] キャンバス、出力解像度、FPS を決める
- [ ] 音声入力、モニター、録画トラックを決める
- [ ] OBS、OS、必要プラグインのバージョンを記録する
- [ ] ライセンスと成果物の公開範囲を決める

## 2. 最小 OBS パックを作る

- [ ] 待機、登壇、休憩、終了シーンを作る
- [ ] ソースと音声バスの命名規則を決める
- [ ] シーンコレクションを秘密情報なしでエクスポートする
- [ ] 別環境でインポート試験を行う

## 3. オーバーレイを連携する

- [ ] セーフエリアと基準グリッドを `sedec-d11n` で決める
- [ ] `sedec-web` にタイトル、登壇者、進行状況、休憩表示の固定 URL を用意する
- [ ] 本番 URL を OBS シーンへ登録する
- [ ] VPS またはネットワーク障害時のローカル代替画面を作る
- [ ] 本番画面とローカル代替画面を 1920 × 1080 と縮小表示で確認する
- [ ] 本番 URL からローカル代替画面へ切り替える手順を確認する

## 4. リハーサルと配布

- [ ] 30 分以上のリハーサル録画を行う
- [ ] フレーム落ち、同期、音量、可読性を確認する
- [ ] オペレーター手順を `sedec-d11n` に反映する
- [ ] 配布単位とバージョン方式を決める

## 5. 発展項目

- [ ] スティンガーと音声ダッキング
- [ ] メディア取り込み・設定検証の自動化
- [ ] ChilloutVR ワールド連携
- [ ] 会場 3D モデルとライティングプリセット
- [ ] ビジュアルリグレッションテスト
